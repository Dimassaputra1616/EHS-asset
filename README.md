## 📱 Progressive Web App (PWA) Features

This system includes native PWA support:
* **Installable:** Desktop & Mobile "Add to Home Screen" prompts.
* **Offline Fallback:** Custom connection lost status page (`public/offline.html`) if network drops.
* **Smart Cache:** Network-first page navigation cache and Stale-while-revalidate for assets.

### Compile Assets for PWA
If you make changes to JavaScript or styling:
```bash
npm run build
```

## 🛠️ Project Setup

1. **Install dependencies:**
   ```bash
   composer install
   npm install
   ```

2. **Database configuration & migrations:**
   Copy `.env.example` to `.env` and set database configurations.
   ```bash
   php artisan key:generate
   php artisan migrate --seed
   ```

3. **Run development server:**
   ```bash
   php artisan serve
   npm run dev
   ```
